核心功能

一键导入

解析书签 HTML，保留原文件夹结构、创建时间与标签。

正文抽取

过滤导航/广告等噪声，专注内容本身；失败自动回退到 OpenGraph 摘要。

智能聚类

用向量语义聚类，自动命名主题；支持手动合并/拆分与固定权威来源。

重复检测

URL 归一化 + 内容哈希（SimHash/MinHash）去重，避免笔记膨胀。

笔记生成

输出“核心定义、要点清单、误区、自测题、延伸阅读”等结构化内容。

多端导出

Markdown / Notion / Obsidian，一键同步与版本管理。

隐私选项：可选择“仅本地处理”；在线模式将遵守 robots.txt 并限速抓取。

工作原理（Pipeline）

  1. 导入：解析 bookmarks.html，获取 URL、标题、原始文件夹、添加时间。
  2. 抓取：并发请求、重试与超时控制。
  3. 抽取：trafilatura/readability 提纯正文，语言检测与清洗。
  4. 向量化：中文优化模型（如 bge/m3e），段落级切块。
  5. 聚类与命名：HDBSCAN/BERTopic + 关键词抽取，自动生成主题名。
  6. 生成笔记：汇总要点、误区、自测题及参考链接。
  7. 导出：Markdown/Notion/Obsidian。

什么是“AI 书签整理”？（SEO 长文模块）

传统的书签管理仅以标题与 URL 为维度，无法反映网页的真实内容。AI 书签整理通过对网页正文进行语义理解，实现跨站点、跨浏览器的主题归档与去重，并进一步产出可复用的学习笔记。核心优势包括：降低重复收集、缩短检索时间、促进系统化学习。

与标签/文件夹的区别

  • 自动化：无需手动打标签，随导随分。
  • 语义级：识别近义与同类话题，避免“同义不同词”。
  • 可沉淀：直接产出结构化笔记，利于复习与分享。

最佳实践

  1. 先做一次全量导入，清理僵尸链接与明显重复。
  2. 将权威来源固定为“优先引用”。
  3. 为重要主题设置复习频率与提醒。
